# Feature Roadmap

## Phase 1 (MVP)
- Home page (header, hero, about, projects preview, experience, contact, footer)
- All-projects page with live hover previews
- Project details pages (features, challenges, release history, live preview)
- Dark / light theme toggle
- SEO metadata and Progressive Web App / offline support

## Phase 2
- Screenshots gallery with lightbox on project detail pages (in progress)
- Real gallery images populated for every project
- Contact form with validation and email integration

## Phase 3
- Blog / writing section
- Testimonials or recommendations
- Skills visualization
- Project filtering and search on the all-projects page
