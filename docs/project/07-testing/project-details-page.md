# Project Details Page — Test Plan

## How to Use
Work through each check from top to bottom. Tick the box once you have confirmed it works on screen. If something does not behave as described, leave it unticked and write a quick note of what happened under Notes.

## Checks
- [ ] **Open any project from the projects page** — its details page loads with a large banner image, the project name, and buttons at the top
- [ ] **Click "Back to Projects"** — you return to the list of all projects
- [ ] **Click "Live Demo"** — the live website opens in a new tab
- [ ] **Read the "About This Project" section** — a short and a longer description are shown
- [ ] **Look for the "Gallery" section** — for a project that has screenshots, a grid of images appears below the description
- [ ] **Click a gallery image** — it opens larger in a full-screen view over a dark background
- [ ] **In the full-screen image, click the arrows** — the next / previous screenshot is shown
- [ ] **Press the arrow keys on your keyboard** — the image moves to the next / previous one
- [ ] **Press the Escape key (or click the ✕ / outside the image)** — the full-screen view closes and you are back on the page
- [ ] **Scroll down** — you see Key Features, Challenges, and (for some projects) a release history and a live preview of the site
- [ ] **On the right side, click "Visit Live Site"** — the live website opens in a new tab
- [ ] **Click a share button (X or LinkedIn)** — a share window opens with the project pre-filled
- [ ] **Scroll to "Similar Projects"** — up to three related projects are shown; clicking one opens its details page
- [ ] **Shrink the window to phone size** — the gallery shows two images per row instead of three and everything stays readable

## Notes
- Not every project has a gallery yet — pick one that does to test the gallery and full-screen image checks.
- Projects with a private code repository show a locked "Private Repo" button instead of a working "View Code" link; this is expected.
