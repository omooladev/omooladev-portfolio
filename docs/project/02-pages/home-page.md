# Home Page

## Purpose
The landing page — introduce Omosuyi, give a quick tour of his skills, projects, and experience, and make it easy for a visitor to get in touch.

## Sections
- Header (navigation + theme toggle)
- Hero (intro, name, title, call-to-action buttons)
- About (bio, profile image, social links)
- Projects preview (grid of project cards + "See all projects")
- Experience (work-history timeline)
- Contact (email + LinkedIn CTAs)
- Footer (copyright + social links)
- Floating WhatsApp button

## Features
- Smooth scroll-to-section navigation from the header
- Dark / light theme toggle with saved preference
- Live website preview on hover over a project card
- "Download Resume" button (opens PDF)
- One-click WhatsApp chat, email, and social links
