# All Projects Page

## Purpose
Show every project in one place so a visitor can browse the full body of work and open any project for details.

## Sections
- Header
- Page heading + intro (with a note about the hover preview)
- Projects grid (all project cards)
- Footer
- Floating WhatsApp button

## Features
- Responsive grid (1 column mobile → 2 tablet → 3 desktop)
- Live website preview on hover over a card
- Quick-action buttons on each card (GitHub, live demo)
- "View Details" link to each project's detail page
