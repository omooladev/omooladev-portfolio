# Project Details Page

## Purpose
Give a visitor the full story of a single project — what it is, its features, the challenges behind it, its release history, screenshots, and a live preview — with links to the demo and source.

## Sections
- Hero (project thumbnail background, title, "Back to Projects", Live Demo / View Code buttons)
- About This Project (short + full description)
- Gallery (screenshots, opens a lightbox) — shown only when the project has gallery images
- Key Features (bullet list)
- Challenges & Solutions (bullet list)
- Release History (version timeline) — shown only when the project has releases
- Social & Write-ups (posts / LinkedIn links) — shown only when present
- Live Preview (embedded iframe of the live site)
- Sidebar: Technologies Used, Quick Links, Share This Project
- Similar Projects (up to 3, same category first)

## Features
- Static generation of one page per project (`/projects/[slug]`)
- Per-project SEO metadata (title, description, Open Graph, Twitter card)
- Gallery lightbox with keyboard navigation (←/→/Esc) and thumbnail grid
- Live iframe preview of the deployed site
- Share to X / LinkedIn with pre-filled links
- Private repos disable the GitHub / "View Code" buttons
